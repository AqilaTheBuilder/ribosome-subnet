Ribosome Network — One Epoch on Chain (15 min)
Miners are synthetases (design RNA); validators are chaperones (refold and score). Every value-adding step is measured; every attack path earns zero.
Phase 1 · COMMIT — Synthetases (miners)3 min
1Receive assigned target from the rotating pool Npool = 32  deterministic in (hotkey, epoch)
2Generate K = 4 candidate RNA sequences  GA coupled objective: TM − β·instability, β = 0.1–0.5 operating point
3Publish commitment c = SHA256(payload ‖ salt ‖ epoch ‖ target)  commit-first: nothing to steal, target leakage impossible
↓
Phase 2 · EVALUATE — Chaperones (validators)6 min
4Refold each candidate with the oracle  stub Nussinov → ViennaRNA on testnet → RhoFold+ 3D in Phase 4
5Score against the target: TM-proxy + base-pair F1  validity gate δtm = 0.35 — below gate earns zero
6Duplicate detection on best candidates  k-mer Jaccard ≥ θdup = 0.85 → Sybil copy zeroed, first commit kept
7Composite S = 0.7·TM + 0.3·exp + 0.1·diversity, then sealed  score stays sealed for B = 4 epochs — no oracle grinding
↓
Phase 3 · SET_WEIGHTS — Chaperones2 min
8Consume only scores whose B-epoch hold has elapsed  weights at epoch e come from epoch e − B evaluations
9Normalize and set Yuma-consensus weights on-chain
↓
Phase 4 · REVEAL — Synthetases2 min
10Publish (payload, salt) for public audit  hash mismatch or missed reveal → zero
↓
Phase 5 · ROTATE — Protocol2 min
11Every Trot = 16 epochs swap half the target pool  memorized targets decay; overfitting has no shelf life
12Reject commits naming targets absent from the pool  future-pool knowledge = leak or fault → zero
Commit–reveal anti-theft + anti-Sybil
Delayed reveals (B=4) anti-oracle-grinding
Pool rotation (Trot) anti-overfitting
θdup + diversity bonus Sybil / diversity
